EvilFlowers Catalog (0.16.0)

EvilFlowers Catalog is the server behind ELVIRA, an open-source digital library for research and academia. It speaks OPDS 1.2 and OPDS 2.0 to reading apps, lends DRM-protected titles through Readium LCP, and offers a REST API to manage everything in between.

Authentication

Send Authorization: Bearer <token>. An access token comes from POST /api/v1/token and is renewed with POST /api/v1/token/refresh; an API key (POST /api/v1/api_keys) is a long-lived token used the same way. Reading apps that cannot do either use HTTP Basic with the user's credentials. What a caller sees is always scoped to the catalogs they were granted.

Errors

Errors are RFC 7807 problem details (application/json, with title and detail). A request body that fails validation answers 422 with the offending fields.

Pagination

Collections take page (from 1) and limit and answer {"items": [...], "metadata": {"page", "limit", "pages", "total"}}.
